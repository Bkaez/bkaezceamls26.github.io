what_i_learned: |
 One of the key concepts I learned today was linear interpolation, a method used to estimate unknown values between two known data points. This technique is especially useful when dealing with missing values in time-series datasets.

 To apply this concept, I worked with our environmental dataset and converted the timestamp intervals from one hour to thirty-minute intervals. Since creating additional time points introduced missing PM2.5 values, I used linear interpolation to estimate those values based on neighboring observations. This allowed me to create a more complete and consistent dataset while preserving the overall trends in the data.

 This task was part of the feature engineering process, where we prepare and enhance data before training machine learning models. By increasing the temporal resolution of the dataset and filling in missing values, we can provide the model with more detailed information that may improve its predictive performance. We also discussed how after interpolation model accuracy can be better evaluated using Root Mean Squared Error (RMSE) and R², which help determine how well the model predicts PM2.5 concentrations.
