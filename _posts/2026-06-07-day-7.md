  Today in the first session with my project group and graduate mentor I was introduced to the concept 
  of data visualization. I learned how graphs and charts can help make large datasets easier to understand 
  and interpret. We practiced using pandas plotting functions such as plot.bar() for bar graphs and
  plot.line() for line graphs to visualize data from datasets. We also talked about how different graph 
  types are useful for showing different kinds of information and trends. One of the biggest challenges I 
  had was trying to plot information from a large dataset onto a single graph while still making it look 
  meaningful and readable. Sometimes too much information on one graph can make it harder to understand the 
  data instead of helping. That part made me realize that data visualization is mostly about presenting 
  information clearly and effectively.
  
  In Python 101 with Dr. Mack, we did a recap on functions and jumped into arguments, and parameters, which 
  was a new concept to me. We also practiced writing functions that could take in different values. I also 
  learned about lists and  how lists can store multiple pieces of data inside a single variable. We practiced 
  creating lists, accessing values inside them, and using different functions while working with lists. It was 
  helpful seeing how functions and lists can work together to make programs more organized and efficient, 
  especially when dealing with larger amounts of data.
